MORRIS QA PORTFOLIO · PROJECT 03

QA 單號統計工具

將每月任務、Jira BUG 開單與 QA Worklog 整合成一份可視化的部門報告，方便檢視成員工作量與趨勢。

← 返回作品集首頁

月份任務統計

依年、月讀取 Google Sheets；當月合併已完成與進行中的任務，手動和自動化分開計算。

Jira 即時資料

按報告人統計 BUG，按實際 Worklog 換算工時與人日，並計算每個任務的平均 BUG 數。

圖表與 PDF

提供任務類型、成員工作量、發測高峰、每日趨勢及明細，並可儲存保留網頁版面的 PDF。

統計規則

  • 同一單可以同時有手動與自動化負責人，兩類各自計數。
  • 同一欄有多位負責人時，每位成員各計一單；已確認的拼字與別名會合併。
  • Worklog 以 Jira 記錄的秒數換算：1 天 = 8 小時，1 週 = 5 天。

本機啟動與修改

  1. 安裝 Python 3.10 以上版本，並確認電腦可連線至資料來源。
  2. 取得完整專案資料夾後，設定 jira_config.local.json 的 Jira Token。
  3. 雙擊 START_HERE.bat；首次啟動會安裝 Python 套件。
  4. 在本機開啟 http://127.0.0.1:8766，即可選月份產生報告。

網站專案含 Python、HTML、CSS 與 JavaScript 原始碼，可依團隊需求修改。Jira Token 檔案只保存在本機或內部分享包，不放在公開的作品集。

程式檔案

  • qa_analyzer_web.py：網站服務、Jira 查詢、PDF 匯出。
  • qa_analyzer.py：表單清理、姓名統一與任務統計。
  • web/：頁面樣式、圖表與互動。
  • README.md：完整資料規則、安裝與內網共用說明。
