Morris 的 QA 自動化練習紀錄

記錄 Python、自動化測試、報表整理與工具實作的練習成果

作業一：API 資料轉換報表

內容：練習串接 API、整理資料並輸出成可閱讀的報表格式。

  • 讀取 API 回傳資料並進行欄位轉換。
  • 整理測試資料，輸出成 Excel 或 CSV 報表。
  • 提升人工整理資料的效率與一致性。

作業二：Allure 測試報告

內容：練習使用 pytest 與 Allure 產出自動化測試報告。

  • 建立簡易測試案例並產出 Allure 結果。
  • 整理 PASS / FAIL 狀態，方便快速查看測試結果。
  • 練習將測試報告對外分享與檢視。

作業三：QA 工時與產能分析

內容：練習整理 QA 成員資料，計算工時、產能與報表摘要。

  • 讀取表格資料並統計每位成員的數據。
  • 將結果整理成清楚的摘要格式。
  • 協助快速掌握團隊工作量與分布。

作業四：Git / GitHub 版本控管

內容：練習使用 Git 與 GitHub 管理程式碼版本。

  • 建立 repository 並上傳練習專案。
  • 練習 commit、push、pull 與版本紀錄查看。
  • 理解版本控管與修改追蹤的基本流程。

作業五：Jira Bug開單統計

內容：練習將填入的區間自動拉取成員回報的 Bug 開單數量，最後輸出一覽無遺。

  • 輸入開始與結束日期，自動跨專案拉取 Jira 指定區間 Bug 單並排除 QA 專案。
  • 依 Jira 報告人統計成員 Bug 開單數量。
  • 整理成可點擊執行的 GUI 工具，並提供本機使用說明。

作業六：Jira QA 任務與子任務自動化工具

內容：將 QA Mission 建單、多人任務分派與 Mattermost 通知整合到公司內網 QA LAB，減少人工複製欄位、重複開單及通知遺漏。

  • 輸入 Jira 主任務單號後，自動解析最新 R 版的進測項目、驗證環境與驗證版號，並依環境帶入對應代理；自動帶入的內容仍可手動修改。
  • 將測試案例、開始日期、到期日、Epic Link 與經辦人寫入對應的 Jira 欄位，直接建立 QA Mission。
  • 支援複選多位測試人員，批次建立 Jira 子任務，自動設定經辦人與英文姓名標題，並填入原始預估時間、剩餘時間及獨立 Deadline。
  • 透過 Redis DB3 管理 Jira 與 Mattermost 帳號對應，子任務建立後由機器人發送人員標記、QA 主單標題、連結及完成期限。
  • 使用 Python、FastAPI 與 NiceGUI 開發，整合既有 QA LAB，並透過 GitLab main 分支進行版本控管與自動部署。
