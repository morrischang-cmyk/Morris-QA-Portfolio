Morris 的 QA 自動化練習紀錄

記錄 Python、自動化測試、報表整理與工具實作的練習成果

作業一：API 資料轉換報表

內容：練習串接 API、整理資料並輸出成可閱讀的報表格式。

  • 讀取 API 回傳資料並進行欄位轉換。
  • 整理測試資料，輸出成 Excel 或 CSV 報表。
  • 提升人工整理資料的效率與一致性。

作業二：Allure 測試報告

內容：練習使用 pytest 與 Allure 產出自動化測試報告。

  • 建立簡易測試案例並產出 Allure 結果。
  • 整理 PASS / FAIL 狀態，方便快速查看測試結果。
  • 練習將測試報告對外分享與檢視。

作業三：QA 工時與產能分析

內容：練習整理 QA 成員資料，計算工時、產能與報表摘要。

  • 讀取表格資料並統計每位成員的數據。
  • 將結果整理成清楚的摘要格式。
  • 協助快速掌握團隊工作量與分布。

作業四：Git / GitHub 版本控管

內容：練習使用 Git 與 GitHub 管理程式碼版本。

  • 建立 repository 並上傳練習專案。
  • 練習 commit、push、pull 與版本紀錄查看。
  • 理解版本控管與修改追蹤的基本流程。

作業五：Jira拉單

內容：練習將填入的區間自動拉取成員的 log 時數，最後輸出一覽無遺。

  • 輸入開始與結束日期，自動拉取 Jira 指定區間資料。
  • 依成員帳號與 QA 單名規則統計 log 時數。
